# Browser bot verification

The browser bot uses the ordinary game view, with readable upgrade decisions and
replaceable JS/TS strategy code. Bend owns gameplay, legal choices, navigation
and fallback. See the [operator guide](../examples/survivors/README.md#browser-stream-bot)
and [verification commands](stream-bot-browser-checks.md).

## Tested artifact

The clean browser build identifies revision
`1b781f5f9c67dded3ecf8ee2d20e136c2a8dd425`. Its complete static application
SHA256 is `eaf261d51656775f36b8720011b180695db8211b15f33a14862c198d380faf90`.
Later integration commits change development checks, generated type declarations
and documentation. They do not change that tested browser runtime.

The actual application passed 40 functional cases across Chromium and Linux
Playwright WebKit. These cover normal rendering, upgrade recommendation and
dwell, operator controls, profile isolation, strategy replacement, dependency
edits, memory migration, broken replacements, active failures, fallback, stale
replies, restart and ordinary player mode. A separate ten-case run verified audio
suspension, public recovery, fresh PCM, mute and compact controls in both engines.

Opposing strategies were checked through actual player displacement from the
same initial setup. Both selected goals affected travel. The pre-fix artifact
passed admission checks but failed the spatial assertion, establishing that the
check distinguishes accepted advice from advice that actually controls movement.
The bounded capture protocol and pinned source manifests are part of the checks.

## Laws and preservation

The navigation preference gate checked 82 distinct kernel roots, 14 literal
controls and nine rejected typechecking mutants. The full execution used verifier
SHA256 `63857c9540893f228605c6739a5c3303831d718d0827890e6733f2c4e927d9b7`.
Subsequent verifier boundary typing cleanup received independent review and two
representative kernel checks with identical emitted proof artifacts. It was not
reported as another complete 82-root execution. The final verifier hash is
`1cdf881a2b794706d42dd1373681cf4097d33b69a8e8ac8c9deb165cb3c6d4af`.

Session laws separately cover admission, stale identities, pause, frozen dwell,
stop and one-time restart. Concrete emitted-runtime probes check observations,
physical goal identity, goal completion, threat replanning and public planner
wiring. These complement actual browser checks.

All 63 source files reachable from the existing native bot baseline retain their
baseline hashes. A native C canary and the existing visible/grid wrapper checks
passed. The existing compiler-wrapper recursion check fails on the unchanged
baseline; this report does not claim that every repository test passes.

Independent source reviews covered the implementation, specification, browser
capture protocol, audio freshness and official-kernel gate.

## Limits

Historical real hide/show and automatic run transitions exercise unchanged
lifecycle code. The final 40-case run does not repeat every historical transition.
Victory shares the death lifecycle path and is covered by source inspection and
universal session laws, rather than a natural full-length victory playthrough.
Linux Playwright WebKit is not macOS Safari qualification.

Recording and broadcasting are outside the requested feature. No new 24-hour
session was run. The stopped historical endurance attempt is not qualification
of continuous operation. Hidden tabs and sleeping devices have no uptime promise.
This work does not merge or deploy the feature.
